# Shoe-Dryer-project

**Status: Under Development**

A personal engineering project focused on designing and developing a compact
shoe-drying system using mechanical design, CAD, airflow and basic electronics.

## Project Objective

The aim of this project is to develop a compact system that can efficiently
remove moisture from shoes using controlled airflow and heating.

## Current Development

The project is currently in the design and development stage. Current work
includes:

- Developing the overall system concept
- Creating 3D CAD models using Autodesk Fusion 360
- Designing the airflow system
- Researching suitable motors and heating elements
- Considering electrical and thermal requirements
- Planning prototype assembly and testing

## Technologies & Skills

- Autodesk Fusion 360
- Mechanical design
- Basic electronics
- Electrical calculations
- Airflow and heat transfer
- Prototyping and testing

## Development process

1. Problem identification
2. Requirements and research
3. Concept development
4. CAD design
5. Component selection
6. Prototype development
7. Testing
8. Design improvements

## Future Development

The next stages will involve completing the CAD design, constructing the
prototype and testing airflow, temperature and drying performance.
